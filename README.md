# CupChess🧁

A cozy chess game for beginners. A box of cupcakes travels from the road to Puffy Bakery, and every stop teaches one chess idea.

## Play⏯️
Open `index.html` in a browser, or visit the GitHub Pages link for this repo.

## Features🦅
- Story chapters and a map with 7 levels (Road, Farm, Market, Burger Shop, Castle, Haunted House, Puffy Bakery)
- A lesson before each level, move hints, take-backs, and a coach that warns about risky moves
- Rating, XP, stars, daily goal and streak
- Unlockable cupcake characters and accessories
- Each level has its own opponents, board and painted background

Progress is saved in the browser (localStorage).
